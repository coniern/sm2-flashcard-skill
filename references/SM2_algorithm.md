# SM-2 算法说明
> 本文件是 `sm2-flashcard-skill` 的算法参考文档，讲清楚"间隔重复"为什么有效、SM-2 到底怎么算。写这个文件的目的：让任何读者（包括 AI 助手）不用翻原论文也能完全理解代码在做什么。
## 一、要解决的问题
人类记忆有一个普遍规律：**遗忘曲线**（艾宾浩斯）。刚学完的东西忘得最快，之后遗忘速度逐渐放缓。如果只在"快忘掉的那一刻"复习一次，就能用最少的次数把内容长期记住——这就是**间隔重复（Spaced Repetition）**的基本思想。
- 复习太勤 → 浪费时间
- 复习太晚 → 已经忘了，等于重学
- 在遗忘临界点复习 → 效率最高
难点在于：每个人的记忆强度不同，同一张卡片在不同阶段"临界点"也不同。SM-2 用两个变量自适应地逼近每个人的临界点：
- **难度系数（Ease Factor, EF）**：衡量这张卡对你有多难。越难的卡，复习间隔增长越慢。
- **连续记住次数（repetitions）**：你连续几次"一次就想起"。连续记住次数越多，说明越稳，间隔可以放得越大。
## 二、算法规则（原文要点，Wozniak, 1987）
1. 每张卡片绑定一个难度系数 EF，初始值一律为 **2.5**。
2. 复习间隔按"连续记住次数"推进：
   - 第 1 次记住 → 间隔 **1 天**
   - 第 2 次记住 → 间隔 **6 天**
   - 第 n 次（n ≥ 3）→ 上次间隔 × EF
3. 每次复习，对回忆质量打分 **q ∈ {0,1,2,3,4,5}**：
   - q ≥ 3：算"记住了"，按规则 2 推进；并更新难度系数
   - q < 3：算"忘了"，卡片回到起点（间隔回 1 天、连续次数归零），**EF 不变**
4. 更新难度系数公式：
   ```
   EF' = EF + (0.1 - (5 - q) × (0.08 + (5 - q) × 0.02))
   ```
   - q = 5（完美回忆）：EF 涨，间隔放大更快
   - q = 3（勉强想起）：EF 微降
   - EF 下限 **1.3**（防呆：不会出现每天都要复习的情况）
## 三、对应到本项目的代码
| 算法概念 | 代码位置 | 说明 |
|---|---|---|
| 初始 EF = 2.5 | `sm2.py: DEFAULT_EASE` | 新卡默认难度 |
| 间隔推进 | `sm2.py: next_interval()` | 1 → 6 → ×EF |
| EF 更新 | `sm2.py: adjust_ease()` | 含下限 1.3 |
| 卡片状态机 | `sm2.py: schedule_card()` | 记住/忘记两条分支 |
| 到期判断 | `sm2.py: is_due()` | due ≤ 今天则复习 |
## 四、一张卡片的生命周期（示例）
```
新卡 (reps=0, interval=0, ease=2.5, due=今天)
   │
   ├─ 复习，q=4（记住）─────────────────────────────┐
   │     reps=1, interval=1天, ease=2.5, due=明天    │
   ├─ 复习，q=4（记住）─────────────────────────────┤
   │     reps=2, interval=6天, ease=2.5              │
   ├─ 复习，q=4（记住）─────────────────────────────┤
   │     reps=3, interval=15天, ease=2.5             │
   ├─ 复习，q=1（忘了！）───────────────────────────┤
   │     reps=0, interval=1天, ease 不变             │ ← 回到起点重学
   └─ 复习，q=5（完美）─────────────────────────────┘
         reps=1, interval=1天, ease=2.6（难度下降）
```
## 五、为什么说它"成熟"
- **有理论依据**：SM-2 是 Anki、SuperMemo 等成熟软件使用/演进的算法，不是拍脑袋。
- **可复算**：公式确定，任何实现只要按规则来，结果一致——这也是我们写单元测试的原因。
- **可扩展**：本实现只做调度，卡组/日志都是 JSON，接界面、接 AI、接云端都容易。
